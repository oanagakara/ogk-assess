Chapter 1

Overview

The NQF Learner Placement Assessment Platform automates the delivery, timing, and scoring of placement assessments. This guide covers everything an assessor needs — from setting up a session to exporting final results.

Key Concepts

Sessions

A session groups multiple learners under a single access code. Learners join by entering the code at the start page. Each session has a configurable seat limit and expiry window. The same session code remains valid until the session expires or all seats are taken.

Attempts

Each learner's individual assessment instance is called an attempt. Attempts move through statuses: In Progress → Submitted → Marked. An attempt that was started but not completed becomes Incomplete.

Review Queue

Written-response questions require assessor marking and appear in the Review Queue after a learner submits. Automated marking handles all other question types immediately on submission.

Typical Workflow

  1. Create a session in Sessions → New Session. Share the session code with learners.
  2. Learners join using the code, sign the consent agreement, and begin the timed assessment.
  3. Monitor the session in real time from Sessions → Monitor.
  4. After learners submit, mark written responses from the Review Queue.
  5. View and export results from Results at a Glance.

Chapter 2

Sessions

Sessions are the primary way to run assessments. A session generates a single code that multiple learners use to join and start their individual attempts simultaneously.

Creating a Session

Navigate to Sessions → New Session in the sidebar.

  1. Template — select the assessment template to use for this session.
  2. Click Create Session. The session code is displayed immediately — share it with learners verbally or in writing.
Seat limit and session window The seat limit and session expiry window are set by your platform administrator, not during session creation. Contact your administrator if the defaults need adjusting for a sitting.
Tip You can reuse a session code for the full duration of the session window. Learners can join one at a time as long as seats remain and the session has not expired.

Monitoring a Session

Open the monitor from Sessions → click Monitor next to an active session.

The monitor shows a live table of all learners who have joined, including:

  • Learner name and workstation number
  • Current attempt status
  • Questions answered vs total
  • Time elapsed and remaining

The page refreshes automatically every 30 seconds. You can also refresh manually at any time.

Note The monitor is read-only. To act on a specific attempt (e.g. unlock it), go to Attempts and find the learner by name or code.

Seat Limits

A seat is considered occupied as soon as a learner joins — regardless of whether they complete the assessment. Seats are not released if a learner abandons or is disconnected.

Important If a learner fails to complete and you need to accommodate a replacement, the session seat limit may need to be increased, or a new session created. Contact your system administrator if you need to adjust a seat limit after a session is created.

Chapter 3

Attempts

Attempt Statuses

Status Meaning
In ProgressLearner has started and is actively working through questions.
SubmittedLearner has submitted. Automated marking has run; written responses (if any) are awaiting assessor review.
MarkedAll questions have been scored, including any written responses. Results are finalised.
IncompleteThe assessment window expired before the learner submitted. The attempt contains whatever the learner answered before time ran out.

Viewing Attempts

Navigate to Attempts in the sidebar. Tabs filter the list by status. You can also search by learner name or attempt code using the filter row at the top of the table.

Click any attempt row to open its detail view, which shows all question responses, auto-mark scores, and a link to the scoring breakdown.

Unlocking an Attempt

If a learner is disconnected mid-attempt and cannot rejoin, their attempt may be locked in a state that prevents re-entry. Unlocking resets the attempt to In Progress so the learner can continue.

No data is lost when unlocking. All previously saved answers are retained. The learner resumes from where they left off. Only use unlock when the learner is present and ready to continue.

To unlock: open the attempt detail view → click Unlock Attempt. The learner can then re-enter using their original attempt code.

Chapter 4

Marking & Review Queue

The platform automatically scores all question types except written responses (GEN-G-WRITE), which require an assessor to read and award marks manually.

The Review Queue

The Review Queue in the sidebar shows all submitted attempts that contain at least one written response pending assessor scoring. The badge count updates as you work through the queue.

Attempts with all written responses scored and no outstanding items are automatically moved to Marked and removed from the queue.

Marking Written Responses

  1. Click an attempt in the Review Queue to open the marking view.
  2. The learner's written response is displayed in full. The marking rubric is shown alongside it.
  3. Enter the mark in the score field. Marks must be within the question's maximum.
  4. Optionally add an assessor note.
  5. Click Save & Next to proceed to the next unscored response, or Save & Exit to return to the queue.
Tip You can return to an already-marked response and adjust the score at any time before the attempt is moderated and finalised.

Score Audit Log

Every score change — whether from automated marking or assessor input — is recorded in the audit log. To view it, open an attempt and click Audit Log.

The log shows the question, the score awarded, who awarded it (system or assessor username), and the timestamp. This record is immutable and is retained for moderation and quality assurance purposes.

Chapter 5

Results & Export

Results Overview

Navigate to Results at a Glance under Attempts. This view shows all marked attempts in a summary table, including the learner's name, total score, section scores, and placement outcome.

You can filter the table by session, date range, or placement outcome. Results are only shown for attempts with status Marked.

Understanding placement levels For a full breakdown of how NQF levels are calculated from marks, see Chapter 8 — Literacy Grade Bands.

Exporting to CSV

Click Export CSV from the Results page. The download includes one row per marked attempt with columns for:

  • Learner name, ID number, and contact details
  • Attempt code and session code
  • Date and time of assessment
  • Total score and per-section scores
  • Placement recommendation
Note Filters applied on the Results page are reflected in the export. To export all results, clear all filters before clicking Export CSV.

Chapter 6

Handwritten Submissions

Some learners may choose to handwrite their essay response rather than type it. When this happens, the assessor scans or photographs the handwritten page and attaches it to the attempt before marking.

How It Works for the Learner

During Section 2, learners encounter the writing question. Before answering, they are asked whether they want to type or handwrite their response.

  • If they choose type, they write directly in the text box on screen.
  • If they choose handwrite, they receive a blank page. They write their essay by hand and hand it to the assessor when they submit.

Uploading a Handwritten Submission

  1. Collect the handwritten page from the learner when they submit.
  2. Open the attempt from the Review Queue or Attempts list.
  3. In the marking view, find the writing submission card and click Upload.
  4. Select the scan or photo of the handwritten page. Accepted formats: JPEG, PNG, PDF.
  5. The image is attached to the attempt. Use View to open it alongside the scoring form when you mark.
Important Upload the handwritten page before finalising the attempt. If the page is lost, note this in the assessor note field and score based on what is available.

Chapter 7

Roles & Permissions

Every user account is assigned a role that determines which actions they can perform. When adding a new user, select the role that matches their responsibilities — they will only see the parts of the platform relevant to that role.

Role Overview

Assessor

Day-to-day assessment delivery

Can run sessions, monitor learners, mark written responses, view results, and export data. Cannot unlock finalised attempts or moderate scores.

Moderator

Quality assurance and moderation

All assessor capabilities, plus: unlock finalised attempts, access the moderation view, view scoring breakdowns, and invite other assessors or moderators.

Auditor

Oversight and reporting

All moderator capabilities, plus: access the per-attempt score audit log and export all results to CSV. Intended for compliance and reporting roles.

Role hierarchy Each role includes all capabilities of the roles below it. Auditor > Moderator > Assessor.

Switching Roles

Moderators and Auditors can temporarily operate with Assessor-level access without changing their account role. This is useful when you want to mark responses without access to moderation actions.

To switch: use the role selector in the bottom of the sidebar. Select Assessor to downgrade, or your real role to restore full access. The change takes effect immediately and applies only to your current session.

Note Role switching is a session-level change only. Your account role does not change, and the switch is reversed the next time you log in.

Inviting Users

To add a new user, navigate to Invite User (accessible from the dashboard or account area). Select the role appropriate for the new user based on the matrix above, then send them the invite link.

Important Invite links expire after 48 hours. If the new user does not register in time, a new invite must be generated. Only Moderators and Auditors can generate invites for Moderator-level roles.

Chapter 8

NQF Placement Levels

Template scope This chapter covers the NQF Literacy Placement Assessment — General template only. Other templates have different sections and mark distributions. Their level grading will be documented here as each template is introduced.

How Levels Are Assigned

Questions are grouped into seven parts (GEN-A through GEN-G) across two sections. Each part contributes to the learner's total mark. The overall literacy placement is determined by the combined percentage scored across all seven parts, mapped to an NQF level using the standard bands shown below.

Literacy Grade Bands

L1 Below basic competency L2 Basic competency L3 Intermediate competency L4 Competent
Part Description Max NQF L1 NQF L2 NQF L3 NQF L4
Section 1 — NQF Level 1–2
GEN-AVocabulary11 0 – 45 – 67 – 89 – 11
GEN-BReading Comprehension & Connectives10 0 – 34 – 56 – 78 – 10
GEN-CNotice Reading, Cloze & Language17 0 – 67 – 1011 – 1314 – 17
GEN-DSentence Order & Time12 0 – 45 – 78 – 910 – 12
Section 2 — NQF Level 3–4
GEN-EExtended Reading, Vocabulary & Language30 0 – 1112 – 1718 – 2324 – 30
GEN-FReading Comprehension & Analysis20 0 – 78 – 1112 – 1516 – 20
GEN-GWriting assessor-marked8 0 – 345 – 67 – 8
Total marks1080 – 39%40 – 59%60 – 79%80 – 100%

The placement is determined by the total marks achieved across all parts as a combined percentage.

Placement Rules

Overall level = combined percentage across all parts

A learner's total marks from all seven parts are added together and expressed as a percentage of the maximum 108. That percentage determines the overall NQF level.

GEN-G is the only manually marked part

All other parts are auto-marked on submission. GEN-G (Writing) goes to the Review Queue and must be scored before the overall placement is finalised.

Levels are computed, not stored as fixed values

The platform recalculates the placement each time a score changes. The level shown in Results always reflects the current state of all marks.

Other templates

Templates other than the General Literacy template may have different sections, different parts, and different mark distributions. Their grading bands will be added to this guide when those templates are in use.
